# Проверка бюджета — 27.11.2026

## Результат

Реализованы детализация доходов/расходов, каталоги вакансий и подработок, найм/отказ/повышение/увольнение, сохраняемая вторая занятость, открытие бизнеса через общую карьерную модель, выбор cash/deposit, продажа имущества с предпросмотром и погашением залога. Денежный остаток остаётся в LocalBudget. Действия защищены владельцем, версией, ключом идемпотентности и блокировкой сессии. Полные правила и ограничения: [budget-management.md](budget-management.md). Контракт: [openapi.yaml](openapi.yaml), версия 0.11.0.

Frontend не изменялся. Новая статистика в рабочую БД не загружалась; расчёт предложений использует прежнюю калибровку сохранения и существующие данные 36 стран. Номиналы, графики, распределение повседневных расходов и ставка вклада явно обозначены игровыми допущениями.

## Ограничения

- Аренда имущества и арендные поступления пока отсутствуют; API возвращает явный признак отсутствующей модели.
- Облигации, фонды, индекс и торговля присутствуют в каталоге, но недоступны с причиной. Работают cash и прежний игровой вклад 1% годовых.
- Для старой работы могут быть неизвестны часы и точная привязка прошлых зарплат. Старые объединённые расходы не перераспределяются задним числом.
- Бизнес заменяет основную работу и несовместим с подработкой. Закрытие дела остаётся в сюжетах. Риск каталога — описательный игровой индекс; отдельная вероятность для каждого вида бизнеса не откалибрована.
- Прогноз условный, на два месяца, без будущих решений/случайных событий/смерти. Точный срок погашения долга не обещается.
- Цена продажи задаётся документированным игровым правилом; рыночных котировок недвижимости/транспорта и частичных продаж нет.
- Изменяющие команды доступны с 18 лет для сгенерированного local; при pendingDecision и COMPLETE заблокированы. Для 1in8b и прежнего демо возвращается явная недоступность.
