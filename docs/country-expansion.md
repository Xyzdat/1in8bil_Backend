# Расширение стран: OpenAPI 0.7.1

Релиз `birth-context-2026-v2`: **36 стран**, из них **33 добавлены**. Индия была доступна ранее; Россия и Япония сохранены.

Для каждой страны доступны рождения, мировая вероятность рождения, ожидаемая продолжительность жизни, смертность до пяти лет, соотношение полов, ВВП на душу населения, урбанизация, языки, религиозные доли, валюта и возрастная смертность. Пробелов в выбранных показателях и годах не обнаружено; вымышленные статистические значения не добавлялись.

Демография и соотношение полов — ООН WPP 2024, средний прогноз на 2026 год. SRB делится на 100 для получения отношения мальчиков к девочкам. ВВП (текущие USD) и урбанизация — WDI 2023, выпуск от 11.11.2026. Религии — Pew, население 2020 года; языки и валюты — CLDR 48. Источники, лицензии и ограничения: [statistical-sources.md](statistical-sources.md).

Таблицы смертности: **559 944 строки** = 36 стран × 2 пола × 77 лет (2024–2100) × 101 возраст (0–100). Снимок разделён по странам и сжат в gzip; импорт выполняется пакетами по 1000 строк. SHA-256 результатов и источников — в `src/main/resources/statistics/expanded-v2/manifest.json`.

## Совместимость

Старые релизы v1 и WDI 2023 сохранены. В БД есть исторические версии профилей IND/JPN/RUS: это отдельные снимки источников, а не дубли в списке выбора. Их значения qx/mx нового и старого релизов полностью совпадают. Смертность старой жизни читает её сохранённый релиз; новый набор не пересоздаёт персонажей и не меняет сохранённые факты рождения или вероятности.

Схема БД не меняется: таблицы V5 уже поддерживают несколько релизов. Новая Flyway-миграция не требуется; импорт выполняется отдельной транзакционной командой и не обновляет пользовательские сессии.

Состав семьи, достаток, профессии, жильё и близость остаются явно обозначенной игровой моделью. Имена — небольшой авторский список для каждой страны, не статистика частот или полная модель культурного разнообразия. Неизвестные города, регионы, владение жильём и электричество остаются неизвестными. Доходы и цены не становятся национальными ценами при выборе страны; валюта кошелька определяется `finances.currency`.

## Frontend: только подключение, без изменения вёрстки

1. В `src/api/sessionTypes.ts` расширить ISO3 union в BirthFacts и запросе генерации по SupportedCountry из OpenAPI.
2. В `src/api/sessionDecoders.ts` расширить оба enum с RUS/JPN/IND: для birthFacts.countryIso3 и запроса генерации. Иначе ответ новой страны будет отвергнут декодером.
3. Сохранить ISO2 в character.birthplace.countryCode, запрос отправлять с ISO3: CHN — запрос, CN — ответ в birthplace.
4. Если уже есть выбор страны, расширить его список. Если выбора нет, `{}` автоматически выбирает среди 36 стран с весами по числу рождений. Новые экраны и стили не нужны.
5. Валюту карточки брать из birthFacts.currency, деньги игры — из finances.currency. Не ограничивать карточку валютами RUB/JPY/INR, не менять сохранённый id и не пересчитывать старый selectionProbability по новому списку.

Маршруты и структуры ответа сохранены. Пример: POST `/api/v1/sessions/generated/local` с `{"countryIso3":"CHN","birthYear":2026}`. Cookie гостя и новый Idempotency-Key обязательны. Неизвестный ISO3 возвращает 400 INVALID_COUNTRY; неверный формат — ошибку валидации 400. У новых жизней statisticsRelease=birth-context-2026-v2, версия движка остаётся childhood-2.

## Воспроизведение и проверка

Обычный запуск использует включённый снимок без внешней сети. Повторное извлечение: `scripts/download-expanded-statistics.ps1`, затем `node scripts/prepare-country-expansion.mjs`. Проверяются исходные SHA-256, покрытие, диапазоны, уникальность и совпадение старой смертности. Изменённый релиз не перезаписывается. `prepare-expanded-statistics.mjs` относится к прежнему набору трёх стран.

```powershell
docker compose build backend
docker compose run --rm --no-deps backend --spring.main.web-application-type=none --life.statistics.import=true
docker compose up -d --no-deps --wait backend
.\scripts\Test-LocalLife.ps1 -Country CHN
```

Автотесты: 24 без ошибок и пропусков, отдельная PostgreSQL. Проверены все 36 стран через HTTP, повтор создания/импорта, отказ для неизвестных кодов, обе версии смертности, прежние сценарии сохранений и 1in8b с подменными ответами. Отдельно проверено совпадение enum OpenAPI и каталога.

Рабочая проверка 24.11.2026: Docker backend обновлён и healthy на 8081; в PostgreSQL подтверждены 36 профилей и 559 944 строки v2, старые 3 профиля и 46 662 строки v1 сохранены. Все 50 прежних сессий (сумма версий 1930) совпали по контрольной сумме до и после импорта. Резервная копия — `target/backups/life-before-country-expansion.sql`, исключена из Git. HTTP-прогон новой китайской жизни дошёл до 7 лет / 84 месяцев: 51 запись, 8 решений, аура +16, 3 родственника. Повтор шага и восстановление через GET проверены. Создано отдельное тестовое сохранение; frontend не изменялся.
